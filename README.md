# いろあめ 🌈
### RGB Drop Studio

**色をつくる。好きが浮かぶ。**

赤、緑、青をひとしずくずつ  
あなただけの色を、この空間に

*いろあめ* は、RGBの3色を混ぜながら、自分だけの色をつくって集める小さなWebアプリです

## ✨ Features

- **Color Mixing** — RGBスライダーで自由に色をつくる
- **Droplet Animation** — 色を注ぐアニメーション
- **My Colors** — お気に入りの色をしずくとして保存
- **Color Codes** — HEXカラーコードをワンタップでコピー
- **Remix** — 保存した色から新しい色をつくる
- **Local Storage** — 保存した色をブラウザ内に保持
- **Responsive Design** — スマートフォン・PCの両方に対応

## 🎨 How to Use

1. RGBの3本のスライダーを動かして色を混ぜる
2. 気に入った色ができたら「この色を保存」を押す
3. 保存したしずくをタップして、色を確認する
4. カラーコードをコピーしたり、もう一度色を混ぜたりして楽しむ

## 🛠 Built With

- HTML5
- CSS3
- Vanilla JavaScript
- SVG
- Web Storage API

外部ライブラリやフレームワークは使用していません

## 🚀 Getting Started

このリポジトリをクローンします

```bash
git clone https://github.com/YOUR_USERNAME/iro-no-shizuku.git
```

`index.html` をブラウザで開くだけで使用できます

インストールやビルドは必要ありません

## 🔒 Privacy

作成・保存した色はブラウザの `localStorage` に保存されます

アカウント登録や外部サーバーへのデータ送信は必要ありません

ブラウザの保存データを削除すると、保存した色も失われる場合があります
